## 📌 Project Overview
A REST API developed using **Node.js** and **Express.js** to manage student course enrollments. All records are maintained in an in-memory JavaScript array with complete validation, error handling, and appropriate HTTP status codes (200, 201, 400, 404).

---

## 📋 Record Structure

| Field | Data Type | Description | Validation |
|---|---|---|---|
| `id` | Number | Unique numeric ID generated by the server | Auto-generated numeric identifier |
| `studentName` | String | Full name of student | Required, non-empty string |
| `courseCode` | String | Unique course code (e.g. CS301) | Required, non-empty string |
| `courseName` | String | Name of enrolled course | Required, non-empty string |
| `semester` | Number | Current semester | Required, **positive integer (> 0)** |
| `attendance` | Number | Attendance percentage | Required, numeric between **0 and 100** |

## 🛣️ API Endpoints & Specifications

> **⚠️ Route Precedence Note:**  
> Specific routes (`/low-attendance`, `/filter`) are declared **before** the dynamic `/:id` route in Express to avoid them being captured as an ID parameter.

### 1. GET All Records
- **Endpoint:** `GET /api/enrollments`
- **Description:** Returns all course enrollment records.
- **Response:** `200 OK`

---

### 2. GET Low-Attendance Enrollments
- **Endpoint:** `GET /api/enrollments/low-attendance`
- **Description:** Returns only records where `attendance < 75`.
- **Response:** `200 OK` (returns array, even if empty `[]`)

---

### 3. Filter Records by Semester
- **Endpoint:** `GET /api/enrollments/filter?semester=3`
- **Description:** Filters enrollments by semester using query parameter.
- **Response:** `200 OK` (returns matching array, or `[]` if none match)

---

### 4. GET Enrollment by ID
- **Endpoint:** `GET /api/enrollments/:id`
- **Description:** Returns the matching enrollment record.
- **Responses:**
  - `200 OK` if record found.
  - `404 Not Found` if ID does not exist.

---

### 5. POST a New Enrollment
- **Endpoint:** `POST /api/enrollments`
- **Headers:** `Content-Type: application/json`
- **Request Body:**
```json
{
  "studentName": "Ishita Rao",
  "courseCode": "CS315",
  "courseName": "Operating Systems",
  "semester": 3,
  "attendance": 88
}
```
- **Validation Rules:**
  - `studentName`, `courseCode`, `courseName`: Required non-empty strings.
  - `semester`: Must be a positive integer (`> 0`).
  - `attendance`: Must be a numeric value between 0 and 100.
- **Responses:**
  - `201 Created` with created record including auto-generated unique `id`.
  - `400 Bad Request` if input is invalid.

---

### 6. PUT / Update an Enrollment
- **Endpoint:** `PUT /api/enrollments/:id`
- **Headers:** `Content-Type: application/json`
- **Request Body:**
```json
{
  "studentName": "Aarav Gupta",
  "courseCode": "CS301",
  "courseName": "Data Structures",
  "semester": 4,
  "attendance": 85
}
```
- **Responses:**
  - `200 OK` with updated record.
  - `400 Bad Request` if payload validation fails.
  - `404 Not Found` if ID does not exist.

---

### 7. DELETE an Enrollment
- **Endpoint:** `DELETE /api/enrollments/:id`
- **Responses:**
  - `200 OK` with `{ "message": "Enrollment with ID 602 deleted successfully.", "deletedRecord": {...} }`.
  - `404 Not Found` if ID does not exist.

```bash
  -H "Content-Type: application/json" \

# 7. Delete enrollment
curl -X DELETE http://localhost:3000/api/enrollments/602
```
